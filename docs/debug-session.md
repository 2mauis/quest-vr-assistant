# 会前与阶段验收

运行 `npm run doctor`，失败项处理后重跑。脚本只读检查，不授予权限、不安装组件、不改网络、不输出设备标识或 gh 凭据。

用户会前清单：确认桌面应用登录、Voice、Screen context；屏幕录制、Screen & System Audio Recording、辅助功能、麦克风与各应用首次 Computer Use 授权由用户处理。打开 MQDH Cast 并置前，关闭含敏感信息的窗口。确认平台审批模式，不把 Always allow 用于合并。不要清除既有浏览器登录。

采集：`npm run quest-capture -- 10 --source adb --eye left`；需要 adb、ffmpeg、唯一已授权设备。默认保留完整画面；显式选择单眼时假设双眼横排裁剪，再以 2 fps 输出逐帧和拼图。单眼/不同布局须先验证，不能盲信裁剪。`--source mqdh` 导入最近五分钟的最新 mp4；可用 `QUEST_MQDH_CAPTURES` 指定目录。MQDH 先手动录制再导入，logcat 和可选 `QUEST_RELAY_LOG` 切片仅覆盖导入时段，不能冒充录制时段日志。所有视频、原始日志和状态均在忽略的 `.debug-evidence/`，采集可能含系统 UI，分享前必须裁剪与脱敏。

显示构建运行 `npm run build:display`，`?debug=1` 开水印，默认隐藏；body 的 `data-build-id`、`data-built-at` 总是可查，显示端 `/api/debug/build` 返回构建文件。同一 SHA 的未提交变更无法靠 SHA 区分，须结合构建时间；时间为状态更新时刻。DOM 水印在沉浸 WebXR 中是否可见待验证。

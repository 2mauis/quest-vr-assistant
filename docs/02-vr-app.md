# 显示页

当前可运行的显示端是 [apps/web-display](../apps/web-display/index.html)。它使用 three.js，在桌面浏览器里作为头显画面的替身，并保留进入 WebXR 会话的按钮。头显浏览器上的沉浸式会话尚未实测。

预设场景是 `grid`、`orbit`、`crystal` 和 `pedestal`。`show_scene` 也可以给出允许列表内、以 `.gltf` 或 `.glb` 结尾的 https 地址，以及位置、旋转、缩放和锚点。`render_panel` 在场景中放一块纯文本面板。`clear` 必须显式给出 `scene`、`panel` 或 `all`。

页面断开后按 1、2、4、8、16、30 秒退避重连，并带 ±20% 抖动。重连时提交上次看到的序号。25 秒发送心跳，60 秒没有入站消息则断开。标签页进入后台导致连接断开时，靠这条补发路径恢复。

原生空间应用仍是以后的候选，不在本次本地闭环里实现。本目录不内嵌模型网页，也不保存云端长期密钥。

# 决策与待机主拍板事项

> 待 VPS 改版更新：VPS 调研未返回，套餐选择不能视为已决定。

## 已确定

- 主线为独立原生 VR app，语音交互与 3D 浮空面板；不走 APK 套壳。
- 「Hey Friday」与声纹验证均在头显本地运行。
- 路线 M：云端 Grok Bot 调 VR 远程 MCP；多个 MCP 可并存，Git、X 复用已有连接器。
- 公网中转只使用 VPS、Caddy、Node、systemd；域名和秘密只在私有部署配置填写。

## 待拍板

| 决策 | 推荐起点 | 拍板前证据 / 影响 |
|---|---|---|
| 原生引擎 | Meta Spatial SDK | M0 实机面板、中文、原生模型支持；复杂三维需求强则评估 Unity |
| VPS 套餐与预算 | 待 VPS 改版更新，暂不指定 | 匿名区域延迟、月费、流量、IPv4、≥1GB、Ubuntu LTS；见费用占位表 |
| Bot 输入入口 | 先验证 routine webhook | 不能假定 MCP 接收对话；失败或延迟超标则决定接受限制还是另立直连语音实验，后者不能冒充路线 M |
| MCP 鉴权方式 | 以真实客户端能力为准 | 验证静态头或标准授权支持，确定凭据轮换与撤销流程 |
| 本地模型 | openWakeWord / sherpa-onnx + ECAPA | 模型许可、算子、唤醒阈值、声纹抗回放与时延 |
| 会话长度与补句 | 空闲 30 秒失效，质量不足补句 | 安全与交互延迟取舍，不移除声纹验证 |
| 可选 grok-voice | 默认关闭付费直连 | 确认定价与预算；本地 STT + MCP 显示不依赖此服务 |
| 分发和生命周期 | 先开发测试安装 | 核实开发流程、许可、权限与失焦行为，不承诺无限后台采音 |

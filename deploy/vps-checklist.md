# VPS 部署检查表

> 待 VPS 改版更新：未来施工时逐项执行，本次只编写示例。

- [ ] 复核套餐筛选表、账单周期、Ubuntu LTS、IPv4、内存及流量；公开记录仅用匿名代号。
- [ ] M0 已确认 Bot 输入入口、鉴权与 MCP 协议兼容，不先购买资源掩盖接口缺口。
- [ ] DNS 与公网 HTTP/HTTPS 可达；管理入口受控，Node 仅绑定 localhost。
- [ ] 创建无登录 vr-relay 用户，部署只读构建产物；环境文件 root 所有、0600，所有占位值已在私有文件替换。
- [ ] Caddy 配置验证与 systemd unit 检查通过；运行时版本、架构与 JIT 加固兼容。
- [ ] Let's Encrypt 证书签发成功，Caddy 证书目录可持久写入；测试续期监控和配置重载。
- [ ] healthz 真正反映 Node 就绪；停 Node 时不能仍返回成功。
- [ ] 未授权 MCP/WS 被拒绝；设备只可访问自身会话；配对码到期、次数限制与撤销生效。
- [ ] Streamable HTTP 初始化、tools/list、tools/call、SSE 首事件及时到达，持续连接无代理缓冲。
- [ ] WS 握手、心跳、30 秒断线恢复、100 条缓冲边界、幂等与过期均验证。
- [ ] SIGTERM 停止接收新请求并有限排空，进程重启后旧会话失效；重启风暴产生告警。
- [ ] 日志脱敏，配置 journald 总量与保留周期；开启系统安全更新并安排维护窗口。
- [ ] 完整 Bot → MCP → 头显闭环和端到端首包 P50/P90 达标。
- [ ] 加密备份、恢复演练、版本回滚、密钥轮换均有证据，公开仓库无产物、秘密或真实部署信息。

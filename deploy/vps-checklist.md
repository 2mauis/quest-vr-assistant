# VPS 部署检查表

> 待 VPS 改版更新：以后施工时逐项执行。本次只保留清单，不表示已经执行。

- [ ] 复核套餐、Ubuntu LTS、公网地址、内存及流量。公开记录只用匿名代号。
- [ ] 托管端已经用静态 Bearer 完成一次 MCP 调用；若它要求 OAuth，先补发现流程再购买资源。
- [ ] Node 的两个端口都只绑定 localhost。Caddy 只反代 MCP 端口。
- [ ] 创建无登录用户 vr-relay。环境文件 root 所有、0600，占位符已在私有文件中替换。
- [ ] Caddy 配置验证与 systemd unit 检查通过。
- [ ] 证书签发成功，证书目录可持久写入。
- [ ] 显示端口的 `/healthz` 反映进程就绪。停掉 Node 后，公开的 MCP 路径不能仍表示进程健康。
- [ ] 未授权的 `/mcp` 返回 401。隧道或 Caddy 后面的非 `/mcp` 路径不可用。
- [ ] `server/discover`、`tools/list`、`tools/call` 在 2026-07-28 下通过；旧客户端的 initialize 会话也能调用工具。
- [ ] WebSocket 握手、心跳、断线补发、100 条缓冲、幂等和过期已在目标环境复核。
- [ ] SIGTERM 后进程退出。重启后旧配对会话失效。
- [ ] 日志不含正文、令牌和配对口令。
- [ ] 托管端到显示页的首包 P50/P90 有样本后再下结论。
- [ ] 备份、回滚和密钥轮换有记录。公开仓库没有秘密或真实部署信息。
